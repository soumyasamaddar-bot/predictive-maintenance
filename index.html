Which machines need maintenance first?

A model reads temperature, vibration and other sensor data from 20 machines and estimates the chance each one fails within the next 24 hours. This page shows the results of the latest run.

Machine status board

Each tile is one machine, based on its latest reading. Select a tile to see its details.

How cautious should the alarm be?

Move the slider to change the failure probability needed to raise an alarm. A low threshold misses fewer failures but causes more false alarms.

Model comparison

Four models were trained on the earlier 75% of the timeline and tested on the most recent 25%. Random Forest is the main model.

Read this before trusting the numbers. The sensor data is synthetic: it was generated so that sensors drift before each failure. That makes the scores unrealistically high (ROC-AUC about 0.999). A real factory dataset would give lower scores.
